Code Review

The code review for my CS 499 Computer Science Capstone examines the original Travlr Getaways full-stack web application before the enhancements presented in this ePortfolio. The review provides a walkthrough of the existing application and evaluates its design, functionality, organization, and opportunities for improvement.

During the review, I examine the application from the perspectives of software design and engineering, algorithms and data structures, and database development. I also discuss areas such as maintainability, security, validation, efficiency, and error handling. These observations provided the foundation for the three enhancements completed during CS 499.

The code review demonstrates my ability to analyze an existing software system, identify strengths and weaknesses, and develop a plan for improving the application. The enhanced Travlr Getaways application presented throughout this portfolio reflects the improvements identified during this review.
