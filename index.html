Professional Self-Assessment

Completing the Computer Science program at Southern New Hampshire University has allowed me to develop a broad set of technical and professional skills while gaining experience with software development, databases, algorithms, cybersecurity, full-stack development, embedded systems, and emerging technologies. Throughout the program, I have progressed from learning individual programming concepts to designing and evaluating complete systems. This ePortfolio represents that progression and demonstrates my ability to apply computer science principles to practical problems.

One of the most important skills I developed throughout the program is the ability to approach software as a complete system rather than simply a collection of individual functions. My coursework exposed me to several programming languages, development environments, and architectural approaches. Projects involving Java, C++, Python, JavaScript, Angular, Express, MongoDB, and embedded systems required me to consider maintainability, security, performance, usability, and scalability in addition to basic functionality. These experiences strengthened my ability to evaluate existing software, identify weaknesses, and determine appropriate improvements.

Collaboration and communication have also been important parts of my development as a computer science professional. Software development rarely occurs in isolation. Requirements must be understood, technical decisions must be communicated, and solutions must ultimately address the needs of stakeholders and users. Through project documentation, software design documents, code reviews, diagrams, discussions, and written analysis, I developed greater confidence in communicating technical information to both technical and nontechnical audiences. These skills are important because a technically strong solution still has limited value if its purpose, limitations, and implementation cannot be clearly communicated.

My work with data structures and algorithms strengthened my understanding of how design decisions influence software performance and usability. Rather than viewing algorithms only as academic exercises, I learned to consider how searching, sorting, filtering, and data organization affect real applications. Working with C++ sorting algorithms and later applying algorithmic concepts to application development helped me recognize the importance of selecting solutions based on the structure and requirements of the problem. This knowledge allows me to consider efficiency and scalability while still producing code that is understandable and maintainable.

Database development has been another significant area of growth. I have worked with relational databases using SQL as well as document-oriented databases using MongoDB and Mongoose. These experiences taught me that effective database development involves more than storing information. Database applications require appropriate data models, validation, reliable CRUD operations, error handling, and consideration of data integrity and security. Understanding the relationship between application logic and persistent data has strengthened my ability to develop full-stack systems.

Security has also become an important part of the way I evaluate software. Coursework in secure coding exposed me to vulnerabilities such as improper input validation, hardcoded credentials, SQL injection, insecure error handling, and dependency risks. I learned that security should be considered throughout the software development lifecycle instead of being added only after an application has been completed. This perspective influences how I approach authentication, validation, database access, external dependencies, and application architecture.

The artifacts presented in this ePortfolio demonstrate these skills through the continued enhancement of the Travlr Getaways full-stack web application. The original application was developed using the MEAN stack and provided a useful foundation for demonstrating software design and engineering, algorithms and data structures, and database development. During CS 499, I revisited the application from the perspective of a more experienced developer and identified opportunities to improve its organization, functionality, efficiency, maintainability, and data handling.

The three enhancements demonstrate different areas of computer science while remaining connected as parts of the same application. The software design and engineering enhancement focuses on improving the application's structure and implementation. The algorithms and data structures enhancement demonstrates how data can be searched, sorted, filtered, and managed more effectively. The database enhancement demonstrates improvements involving MongoDB, Mongoose, validation, CRUD functionality, and reliable interaction between the application and its data.

Together, these artifacts represent both my technical abilities and the development process that led to them. My goal is to continue building on these skills as I move into the computer science profession. I want to approach future projects with an understanding that successful software must not only function correctly but also be maintainable, secure, efficient, accessible, and designed around the needs of its users and stakeholders. This ePortfolio demonstrates the foundation I have developed for continuing that growth.
