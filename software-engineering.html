Software Design and Engineering

Artifact: Travlr Getaways

The artifact selected for the Software Design and Engineering category is the Travlr Getaways full-stack web application. The application was originally developed during CS 465 Full Stack Development using the MEAN stack, which consists of MongoDB, Express, Angular, and Node.js. Travlr Getaways provides travel information through a customer-facing website while also supporting administrative functionality for managing trip information.

I selected this artifact because it demonstrates several important areas of software engineering within a single application. The project includes front-end and back-end development, routing, RESTful API communication, reusable components, database integration, and the separation of application responsibilities. Revisiting the project during CS 499 gave me an opportunity to evaluate code that I had previously written and improve it using the knowledge and experience I gained later in the Computer Science program.

Enhancement

The software design and engineering enhancement focused on improving the organization, maintainability, and overall design of the Travlr Getaways application. The existing project provided functional components, but the enhancement process allowed me to examine how those components could be structured more effectively and how responsibilities could be better separated throughout the application.

One important area of improvement involved the application's architecture. Travlr uses an Express-based server, an API layer, MongoDB models, and an Angular administrative interface. Organizing these responsibilities clearly makes the application easier to maintain and allows individual components to be modified without unnecessarily affecting unrelated portions of the system.

The enhancement also reinforced the use of reusable components and services. The Angular administrative application separates the display of trip information from the service responsible for communicating with the REST API. This approach reduces duplicated code and creates a clearer boundary between the user interface and data-access functionality.

Technical Skills Demonstrated

This enhancement demonstrates my ability to work with a full-stack architecture and understand how multiple technologies interact within a complete software system. The application uses Angular for the administrative client, Express and Node.js for server-side functionality, MongoDB and Mongoose for persistent data, and RESTful API endpoints for communication between application layers.

Working with these technologies required consideration of routing, component design, API requests, data models, error handling, and maintainability. Rather than treating each part of the application as an independent programming exercise, the enhancement required me to consider how design decisions in one layer could affect the behavior of the overall system.

Course Outcomes

The enhancement supports the CS 499 course outcomes by demonstrating my ability to design and evaluate computing solutions using appropriate computer science practices. It also demonstrates my ability to analyze an existing application, identify opportunities for improvement, and implement changes that improve the quality and maintainability of the software.

The project also reflects the importance of professional communication and documentation. Understanding an application's architecture and being able to explain why particular design decisions were made are important skills when working with other developers, stakeholders, and technical teams.

Reflection

Revisiting Travlr Getaways showed me how much my approach to software development has changed throughout the Computer Science program. When I originally developed the application, my primary focus was making each required feature work correctly. During the enhancement process, I was able to look beyond basic functionality and consider qualities such as maintainability, organization, scalability, security, and separation of concerns.

This process reinforced the idea that software engineering involves more than writing working code. A successful application should also be understandable and maintainable by other developers and should provide a structure that can accommodate future changes. The enhancement gave me an opportunity to demonstrate those principles using a project that represents a significant part of my full-stack development experience.
