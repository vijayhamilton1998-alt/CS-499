Algorithms and Data Structures

Artifact: Travlr Getaways

The artifact selected for the Algorithms and Data Structures category is the Travlr Getaways full-stack web application. Originally developed during CS 465 Full Stack Development, the application manages a collection of travel packages containing information such as trip codes, names, destinations, dates, prices, and descriptions.

I selected Travlr Getaways for this enhancement because the application's trip data provides an opportunity to demonstrate how algorithms and data organization can improve the way users interact with information. Enhancing the existing project allowed me to move beyond simply retrieving records and consider how data could be searched, filtered, sorted, and presented more efficiently.

Enhancement

The Algorithms and Data Structures enhancement focused on improving how trip information is processed and presented within the application. Search, sorting, and filtering functionality provide users with more control over larger collections of trip records and reduce the need to manually examine every available item.

The enhancement required consideration of how trip objects are stored and manipulated after they are retrieved from the application's API. Collections of trip objects can be processed according to properties such as destination, price, trip name, or other identifying information. This demonstrates the practical use of data structures within an application rather than treating them only as theoretical concepts.

Sorting functionality also demonstrates the importance of algorithmic decision-making. A user may want to organize travel packages according to price or another property. The application must compare values and reorganize the collection while preserving the underlying trip information. Filtering similarly evaluates records against defined criteria and returns only the objects that satisfy the user's request.

Efficiency and Scalability

Algorithm efficiency becomes increasingly important as the amount of application data grows. Operations that appear instantaneous when processing a small number of records can become expensive when applied to much larger datasets. For this reason, developers must consider the number of operations required by searching, sorting, and filtering algorithms and determine whether processing should occur on the client, server, or database layer.

This enhancement strengthened my understanding of the relationship between algorithms and application performance. Selecting an algorithm is not only about obtaining the correct result. The solution should also be understandable, maintainable, and appropriate for the size and structure of the data being processed.

Technical Skills Demonstrated

Through this enhancement, I demonstrated the ability to work with collections of structured objects and apply operations that transform or narrow those collections according to application requirements. These skills include searching, sorting, filtering, comparison logic, iteration, and the organization of application data.

My earlier coursework with data structures and algorithms provided the foundation for evaluating these operations. Applying those concepts to Travlr Getaways helped connect algorithmic theory with full-stack application development and demonstrated how algorithm choices directly affect the user experience.

Course Outcomes

This enhancement supports the CS 499 course outcomes by demonstrating my ability to design and evaluate computing solutions while using algorithmic principles to address practical problems. It demonstrates that I can evaluate multiple approaches to processing data and consider tradeoffs involving efficiency, maintainability, and scalability.

The enhancement also demonstrates my ability to apply computer science concepts across different areas of an application. Algorithms and data structures are closely connected with software engineering and database development because application performance depends on how information is represented, retrieved, processed, and displayed.

Reflection

Completing this enhancement changed the way I think about algorithms within application development. Earlier in the Computer Science program, algorithms were often presented as individual programming problems. Working with Travlr Getaways demonstrated how those same concepts become part of larger systems and directly influence how users interact with an application.

I also gained a stronger appreciation for evaluating solutions based on their context. An approach that works well for a small dataset may not be appropriate when thousands or millions of records are involved. Understanding these tradeoffs will help me design applications that can continue to perform effectively as their requirements and datasets grow.
